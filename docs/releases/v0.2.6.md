# SJTUFitMan v0.2.6 · 未付款订单失效后可重新候补

修复创建候补订单后未付款，订单已被平台取消，但助手仍永久阻止预约相同时段的问题。

- 重新启动候补时先查询原订单号，核对场地、日期和全部预约小时。网站明确返回取消或过期状态后，解除该订单的重复下单限制并继续查询。
- 仍待付款、已支付、申诉/退款中或无法确认的订单继续保留保护，不重复下单。
- 支持一小时、连续两小时及两种预约计划；旧版记录可直接使用，不需删除历史文件。
- 原来的成功订单和邮件记录保留；新抢到的订单单独发送付款提醒。
- “记录”展示待付款、已支付及最近核查的取消/过期状态。
- README 改为面向使用者的下载、登录、邮箱、候补与付款说明，维护资料移入独立文档。

下载本页附件 **SJTUFitMan-v0.2.6-windows-x64.zip**，完整解压后双击 **交大健身房助手.exe**。需要 64 位 Windows 和 Chrome 或 Edge，无需安装 Python 或 VS Code。

升级前关闭旧程序，把旧目录中的 `config/config.toml` 和 `.local/` 复制到新版本相同位置。订单失效后，请重新点击“保存并启动”；助手不会因为未付款自行重新抢。程序不会自动付款。
