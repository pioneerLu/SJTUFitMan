# SJTUFitMan v0.2.5 · 交大健身房助手

Windows 64 位免安装版。无需安装 Python 或 VS Code；电脑需安装 Google Chrome 或 Microsoft Edge。

## 下载与启动

1. 下载本页附件 **SJTUFitMan-v0.2.5-windows-x64.zip**。
2. 解压整个压缩包，双击文件夹中的 **交大健身房助手.exe**。
3. 在“设置”填写自己的账号和邮箱通知，先登录并发送测试邮件。
4. 在“自动预约”选择计划、日期、时段和查询间隔，点击“保存并启动”。运行期间请保持软件开启。

GitHub 自动生成的 Source code 附件供开发者使用。`.zip.sha256` 是下载完整性校验文件。

## 本版功能

- 同一个界面支持“每日北京时间 12:00 开抢七天后时段”和“指定日期退选候补”。
- 日期、时段使用选项，支持一小时或同一场地的连续两小时。
- 候补可立即或定时开始，可设置查询频次、持续时长或截止时间；候补最晚在目标时段开始时结束。
- 核实预约成功后停止本轮查询，并用邮件提醒付款；发送失败会保留通知并按设置重试。
- Chrome 和 Edge 共用登录、会话恢复与预约流程。验证码在本地识别，失败后支持手动处理，不依赖 LLM。
- 账号、邮箱和预约偏好集中保存在本机 `config/config.toml`，订单和运行记录保存在 `.local/`。

## 升级与验证

升级前关闭旧程序。解压新版本后，将旧目录中的 `config/config.toml` 和 `.local/` 复制到新目录相同位置，即可保留设置、会话和记录。

本版通过 285 项本地测试，以及可执行程序的界面、OCR、OpenCV、浏览器启动、延迟登录填写与退出清理检查。Edge 已完成一次真实自动登录及会话恢复验证；验证码识别和预约成功仍取决于网站状态和实际余量。

程序不会自动付款。收到邮件后，请及时到学校体育平台核对订单并付款。邮件是否进入收件箱取决于邮箱服务，首次使用请确认测试邮件能收到。

发布包只带空白配置样例，不包含维护者的账号、邮箱授权码、会话或订单。
