# SJTUFitMan · 交大健身房助手

在自己的电脑上持续查询健身房名额，有余量时自动创建预约订单，并发送邮件提醒你付款。支持每日中午开抢和退选候补，可选一小时或连续两小时。

**预约成功后需要你到学校体育平台付款，程序不会自动付款。**

## 下载与启动

**[下载最新版 →](https://github.com/pioneerLu/SJTUFitMan/releases/latest)**

1. 在发行页面的附件（Assets）中下载 **`SJTUFitMan-v版本号-windows-x64.zip`**。
2. 将整个压缩包解压到桌面、“下载”或其他可写的文件夹。
3. 双击文件夹中的 **`交大健身房助手.exe`**。

适用于 **64 位 Windows**，电脑需安装 **Google Chrome 或 Microsoft Edge**。无需安装 Python、VS Code 或其他开发工具。请保留整个解压文件夹，不能只移动其中的 exe。

## 第一次使用

### 1. 登录账号

进入 **设置 → 账号与登录**：

1. 选择浏览器；默认“自动选择”即可，也可以指定 Chrome 或 Edge。
2. 填写自己的 jAccount 账号和密码，点击 **保存账号到本地配置**。
3. 点击 **自动登录**。遇到验证码识别失败或其他验证时，按提示在打开的浏览器中手动完成登录。

登录成功后，助手会自动保存登录状态，后续预约优先使用该状态。登录过期时，已保存的账号密码可用于尝试重新登录；需要手动处理时会显示提示。

### 2. 设置邮件提醒

进入 **设置 → 邮箱通知**，填写以下三项：

| 设置 | 填什么 |
| --- | --- |
| 发件邮箱 | 用来发送提醒的邮箱，通常填自己的 QQ 邮箱 |
| 邮箱授权码 | 邮箱提供的第三方客户端授权码，用于允许助手发信 |
| 收件邮箱 | 接收提醒的邮箱，可以和发件邮箱相同 |

提醒会从你填写的**发件邮箱**发出。授权码与邮箱登录密码不同：使用 QQ 邮箱时，在网页版邮箱的设置中寻找 SMTP 或第三方客户端服务，按页面提示开启并获取授权码。可查看 [QQ 邮箱帮助中心](https://service.mail.qq.com/)。

填写后点击 **保存邮箱设置 → 发送测试邮件**，确认收件箱或垃圾邮件中能收到。QQ 邮箱通常可以沿用默认服务器设置；其他邮箱可在“高级邮件设置”填写其服务商提供的参数。

### 3. 选择计划并开始

进入 **自动预约**，选择项目、日期和时段，设置查询间隔与停止条件，然后点击 **保存并启动**。点击此按钮后，助手会在符合条件时创建真实订单。

运行期间请保持**电脑开机、联网、不睡眠，且助手保持运行**。切换到“记录”或“设置”页不会中断任务。

## 两种预约计划怎么选

| 计划 | 适合什么情况 | 成功后怎样处理 |
| --- | --- | --- |
| 指定日期候补 | 已经没有名额，等待有人退选 | 停止此次候补，发送邮件 |
| 每日12点开抢 | 等待中午开放七天后的预约 | 停止当天查询，发送邮件；软件继续运行时次日再执行 |

### 指定日期候补

1. 选择 **指定日期候补**，选择项目、今天至七天后的日期和目标时段。
2. 选择 **立即开始**，或通过 **定时开始** 设置启动时间。
3. 设置查询间隔，以及“持续指定时长”“指定截止时间”或“直到目标时段开始”。
4. 点击 **保存并启动**。

候补会持续等待名额，直到抢到、你点击停止、到达设置的上限，或目标时段开始。连续两小时以第一个小时的开始时间为截止点，例如 `18:00–20:00` 最晚在当天 18:00 停止。

持续时长从计划开始时间计算，登录、查询和等待也计入；可设置 1 分钟至 8 天，但不会晚于目标时段开始。

### 每日12点开抢

1. 选择 **每日12点开抢**，选择项目。
2. 点击 **刷新日期和时段**，添加候选时段并排列优先顺序。
3. 设置查询间隔，以及“持续指定时长”或“指定截止时间”。
4. 点击 **保存并启动**，保持软件运行。

每天**北京时间 12:00** 开始查询，预约日期自动为开抢日的七天后。候选时段按优先顺序尝试，只抢其中一个。

“持续指定时长”是每天从 12:00 起计算的查询上限，可设置 1 分钟至 24 小时；“指定截止时间”是整个每日计划的截止点。成功后停止当天查询，次日继续；要结束整个计划，请点击 **停止**。

### 连续两小时与查询间隔

要预约连续两小时，请选择完整时段，例如 **`18:00–20:00`**。助手要求同一场地的两个小时都可预约，并合成一张订单。每日计划中分别添加 `18:00–19:00` 和 `19:00–20:00` 表示两个备选，而不是同时预约。

查询间隔可设置 **20～600 秒**，从上一次查询结束后计算。登录、验证码和订单核查也会产生网站请求；遇到网站限频或登录异常时，助手会停止并提示处理。

## 抢到后如何付款

看到“待付款”或收到成功邮件后，进入 [学校体育平台](https://sports.sjtu.edu.cn/pc/) 的**个人订单**，核对日期、时段和金额，并在平台规定的期限内付款。

**创建待付款订单不等于完成付款。** 未付款订单可能被平台自动取消，订单的最新状态和付款期限以体育平台为准。

邮件临时发送失败时，助手会保留通知并重试。你也可以在 **记录** 查看发送状态，检查邮箱设置后点击 **重试未发出的邮件**。关闭软件后，漏发通知会保留到下次启动；补发邮件中的订单可能已经付款、取消或过期，请先核对平台状态。

## 常见问题

**未付款订单取消或过期后，还能抢同一时段吗？**

可以。重新点击“保存并启动”时，助手会先核查旧订单；网站确认已取消或过期后，会解除旧订单的限制并继续查询。也可以先在“记录”点击“核查异常订单”。旧订单仍待付款、已支付或状态无法确认时，不会重复创建订单。助手不会在你忽略付款后自行重启候补，需要你再次启动计划。此处理需要 v0.2.6 或更新版本。

**验证码失败怎么办？**

按软件提示在打开的浏览器中手动处理。登录页也可使用“验证码辅助操作”查看放大的完整图片；刷新图片后重新输入答案。

**有名额却停止了怎么办？**

先看软件提示和“记录”。已有待付款订单时，到平台处理；提示登录失效时重新登录；下单结果不明时，先点击“核查异常订单”并核对平台个人订单，再决定是否重新启动。

**为什么没收到邮件？**

先检查收件箱和垃圾邮件，再到“记录”查看邮件状态。授权码无效或重试达到上限时，修正邮箱设置并点击“重试未发出的邮件”。首次使用请先确认测试邮件能收到。

**点击停止或关闭软件，会取消已抢到的订单吗？**

不会。停止只结束查询，已有订单仍需你在体育平台处理。关闭时，助手会等待已经发出的下单请求核实结果后退出，看到“正在关闭”时请稍候。

## 个人数据与升级

个人设置保存在软件文件夹中的 **`config/config.toml`**；登录状态、订单和邮件记录保存在 **`.local/`**。日常设置在界面中填写即可。

账号密码和邮箱授权码以明文保存在本机配置中，请保管好这些文件。分享给同学时，请分享原始发行 ZIP 或下载链接，每个人使用自己的账号和设置。

升级时先关闭软件，将新版解压到新文件夹，再把旧目录中的 **`config/config.toml` 和 `.local/`** 复制到新目录相同位置，即可保留设置、登录状态和记录。

遇到问题可在 [GitHub Issues](https://github.com/pioneerLu/SJTUFitMan/issues) 描述操作步骤、版本号和软件提示。附图前请遮住账号、邮箱等个人信息，不要上传个人配置或登录状态文件。
